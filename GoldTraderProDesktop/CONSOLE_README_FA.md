# راهنمای کنسول خودکار GoldTrader Pro

## اجرای نسخه آماده ویندوز
1. فایل ZIP خروجی GoldTrader Pro را از GitHub Actions دانلود و با Extract All استخراج کنید.
2. وارد پوشه‌ای شوید که فایل GoldTraderPro.exe در آن قرار دارد.
3. روی GoldTraderPro_AutoConsole.bat دوبار کلیک کنید.
4. کنسول برنامه را اجرا می‌کند و پس از بسته‌شدن برنامه، نتیجه را نشان می‌دهد.

نسخه بسته‌بندی‌شده برای اجرای برنامه به نصب جداگانه Python نیاز ندارد. فایل EXE را از پوشه اصلی خودش جدا نکنید؛ پوشه‌های همراه PyInstaller باید کنارش باقی بمانند.

## اجرای سورس پروژه
فایل‌های GoldTraderPro_AutoConsole.bat و GoldTraderPro_AutoConsole.ps1 را در پوشه GoldTraderProDesktop نگه دارید و BAT را اجرا کنید. این حالت به Python 3.11 نسخه 64 بیتی نیاز دارد. کنسول محیط مجازی را آماده می‌کند، وابستگی‌ها را نصب/بررسی می‌کند، نحو کد و تست‌ها را اجرا می‌کند و فقط در صورت موفقیت تست‌ها برنامه را بالا می‌آورد.

## عیب‌یابی
- گزارش هر بار اجرا در پوشه logs ذخیره می‌شود؛ اگر آن پوشه قابل‌نوشتن نباشد، گزارش در %LOCALAPPDATA%\GoldTraderPro\logs قرار می‌گیرد.
- اگر نصب وابستگی‌ها شکست بخورد، کنسول یک بار با مخزن رسمی PyPI دوباره تلاش می‌کند.
- اگر تست‌ها شکست بخورند، برنامه به‌طور خودکار اجرا نمی‌شود؛ متن خطا و مسیر گزارش را از کنسول بردارید.
- برای دریافت داده زنده، MetaTrader 5 باید روی همان ویندوز نصب و به حساب کارگزار متصل باشد و نماد طلا در config/default.json با نماد دقیق کارگزار هماهنگ باشد.
- این برنامه فقط سیگنال ارائه می‌دهد و سفارش خرید/فروش خودکار ارسال نمی‌کند. اگر داده واقعی دردسترس نباشد، نباید قیمت یا سیگنال ساختگی بسازد.
